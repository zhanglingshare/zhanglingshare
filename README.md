## 我在做什么

现实中的城市和产业，已经是一张"人—产业—城"互相咬合的网。只凭经验，越来越难算清一句话：**"如果某个变量变了，会怎样？"**

项目晚两年、龙头扩产落空、一条通勤路拥堵、人口没有按预期增长……这些"万一"，都可以在动手之前先跑一遍。
